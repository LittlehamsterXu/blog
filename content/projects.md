项目页面用于记录已经适合公开的问题、动机、设计、实现和结果。当前项目的名称、设计和创新细节不会提前放到公开网站；代码仓库、报告和 demo 会在具备公开条件后再补充。

{{< callout type="note" title="记录原则" >}}
先记录问题和证据，再记录结果和结论；项目页面不替代代码仓库，也不把未完成的研究包装成最终成果。
{{< /callout >}}

## 公开项目

目前公开项目以安全技术文章、CTF 内容、开源贡献和已经可以分享的工程记录为主。

## 进行中的项目

正在进行的项目暂不公开具体名称、创新点、设计方案、实验方法或未发表结果。等成果可以公开时，再按照 Problem、Design、Result 和 Limitations 补充。

## 安全项目和 CTF

安全项目和 CTF challenge 继续作为独立内容维护，重点记录漏洞原语、分析路径、复现环境、失败尝试和可迁移的经验。它们与编译器安全方向共同构成从 Binary Security 到 Compiler Security 的技术路径。

## Project Entry Template

新增项目时建议保持以下顺序：

1. Problem
2. Motivation
3. Architecture / Key Design
4. Implementation
5. Result
6. Limitations
7. Lessons Learned
8. GitHub / Paper / Report / Demo
