## About Me

我过去主要做 CTF 中的 Reverse Engineering 和 Pwn，建立了传统二进制安全、漏洞分析、逆向工程和系统安全基础。现在则在安全与编译器的交叉地带继续折腾，试图让复杂的 bug 至少变得可解释。

目前主要关注 Compiler Correctness、Compiler Security、AI / ML Compiler、Compiler Testing、Memory Safety、Static Analysis 和 Fuzzing。正在进行中的项目细节不在公开主页展开。

## Technical Path

**Reverse Engineering / Pwn / CTF → Systems Security → Compiler Security → AI Compiler**

这条路径会同时保留在网站中：早期安全内容体现问题分析和系统基础，目前的项目关注编译器语义、正确性、安全边界和 AI infrastructure。
