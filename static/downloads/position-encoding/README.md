# Transformer 位置编码：实验附件

这组脚本把位置向量、Attention 匹配和生成时的位置编号放在一起观察。需要 Python 3.10 以上和 PyTorch，数据都由小 Tensor 构造，直接在 CPU 运行。

## 运行

下载并解压 `experiments.zip`，在解压目录执行：

```bash
python -B verify_positions.py --output-dir ./my-results
```

结果写入 `results.json`；原有正弦位置编码实验的输出写入 `original_stdout.txt`。`-B` 使源码目录保持整洁，避免生成字节码缓存。

记录环境为 PyTorch **2.14.1+cu130**、CPU 单线程。新增的小 Tensor 实验使用 float64；原来的正弦实验使用 float32，RoPE 还单独比较了 float32 的误差。

## 文件

| 文件 | 内容 |
| --- | --- |
| `positional_encoding_experiment.py` | 原学习脚本：三个相同 Token、恒等 Q/K/V 投影，比较加正弦编码前后的分数、权重和输出 |
| `decoder_only.py` | 原学习脚本：带绝对位置表的 TinyDecoderOnly；本组只导入其模型类 |
| `position_encoding.py` | 本文新增：固定正弦编码、二维坐标配对旋转、RoPE |
| `verify_positions.py` | 执行各项实验、检查数值关系并保存结果 |
| `results.json` | 环境、原源码哈希、全部矩阵和数值结果 |
| `original_stdout.txt` | 原正弦实验的控制台输出 |

两份原学习脚本按原始内容保存，SHA-256 记录在结果文件中。验证脚本导入 `decoder_only.py` 的 `TinyDecoderOnly`，不会进入该文件的主程序。本组运行随机初始化模型和固定投影，主要观察计算关系。

## 位置编码接口

```python
pe = sinusoidal_positions(position_ids, d_model=8)
rotated = apply_rope(x, position_ids)
```

- `sinusoidal_positions` 接受形状 `[...]` 的位置编号，返回 `[..., D]`，按 `sin, cos, sin, cos, ...` 排列；`D` 为正偶数。
- `apply_rope` 的输入为 `[B,H,T,d]`，位置编号为 `[T]` 或 `[B,T]`，返回相同形状；`d` 是偶数的 Head 宽度。
- RoPE 将相邻维度 `(0,1)、(2,3)、...` 配对，`rotate_pairs` 把 `(a,b)` 映射成 `(-b,a)`，对应标准旋转矩阵 `[[cos,-sin],[sin,cos]]`。
- 两种编码都使用 `theta_j = 10000^(-2j/d)`。RoPE 在投影、拆分 Head 之后旋转 Q、K；V 按原样参与加权汇总。

## 1. 置换输入与固定位置

`permutation` 使用 `[1,4,4]` 输入、同一组固定 Q/K/V 投影和全可见的 Self-Attention。将 Token 按 `[2,0,3,1]` 置换：

| 对照 | 最大绝对差 |
| --- | ---: |
| 普通 Attention 的输出，与原输出按相同顺序置换 | `2.22044604925e-16` |
| 加上固定正弦位置表后，交换内容、保留位置编号 | `0.726823677819` |

第一项观察的是全可见 Attention 的置换等变；第二项将内容换到不同位置，输入里的位置关系随之改变。

## 2. 正弦编码与四项展开

`D=8` 时，四个频率为 `[1,0.1,0.01,0.001]`。固定正弦位置向量满足：

```text
PE(m) dot PE(n) = sum_j cos((m-n) * theta_j)
```

位置 `(3,5)` 和 `(13,15)` 的点积都约为 `2.56371774796`；位置 `(3,6)` 的点积约为 `1.96488952628`。

接着固定两个内容向量和两组随机投影，展开 `(x_m+p_m)W_Q` 与 `(x_n+p_n)W_K` 的点积，分别记录内容–内容、内容–位置、位置–内容、位置–位置四项。四项求和与直接计算完全对应。位置 `(3,5)` 与 `(13,15)` 的完整原始点积分别为 `6.60753751101`、`11.57333885525`，可以看到内容与位置交叉项的作用。

## 3. RoPE

使用形状 `[1,2,4,8]` 的固定 Q/K，检查：

| 关系 | float64 最大绝对误差 |
| --- | ---: |
| 旋转前后 Q 的范数 | `8.88178419700e-16` |
| 同一位置旋转 Q/K 后的逐位置点积 | `8.88178419700e-16` |
| 全部位置一起加 10 后的分数矩阵 | `1.55431223448e-15` |

相同平移实验在 float32 下的误差为 `4.76837158203e-7`。

再取同一对原始 Q/K 内容向量，仅改变位置：`(3,5)` 和 `(13,15)` 的 Head 0 原始点积都为 `1.35985937550`；把后一个位置改成 6，点积变成 `0.485146352583`。这里同时验证了 `dot(R_m q, R_n k) = dot(q, R_(n-m) k)`。

结果文件保留了完整分数矩阵，以及 `[B,T]` 位置编号、偶数 Head 宽度等接口检查。

## 4. 缓存前向的位置编号

模型沿用原来的 `TinyDecoderOnly` 实现，实验配置为词表 20、宽度 16、4 个 Head、FFN 宽 32、两层 Block、最大长度 16；固定种子 7，以 float64 运行。

输入为 `[2,7,3,11,5,9]`，先缓存前四个 Token，再送入 `[5,9]`：

```text
完整前向的位置：0 1 2 3 4 5
缓存后的新位置：        4 5
对照用的重置位置：      0 1
```

| 前向方式 | 与完整前向的 logits 最大绝对差 |
| --- | ---: |
| 正确位置 `[4,5]` 的缓存前向 | `3.33066907388e-16` |
| 每次输入一个 Token，位置持续增长 | `3.88578058619e-16` |
| 位置 Embedding 重置成 `[0,1]` | `1.17133064219` |

重置对照通过 `pos_emb` 的 forward pre-hook 完成：仅把查表编号从 `[4,5]` 改成 `[0,1]`。Attention 仍然读取真实长度为 4 的历史缓存，因果 Mask 的 Query 编号也仍是 `[4,5]`。这样能单独观察位置向量改变造成的差异。

这些数据来自小尺寸 CPU 实验；每项的张量、投影配置和误差均保存在 `results.json` 中。
